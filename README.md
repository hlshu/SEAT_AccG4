# SEAT-AccG4s

This repository contains 71 drug sensitivity-expression-associated target (SEAT) genes and 308 retained accessible G-quadruplex-forming loci (AccG4) sequence coordinates in the human genome under the genome assembly of **hg19**.

## Files
`SEAT gene.txt`: the gene names of the drug sensitivity-expression-associated target (SEAT) genes.

`SEAT-AccG4.bed`: the coordinates of the accessible G-quadruplex-forming loci (AccG4) sequence associated with SEAT genes in the human genome.

The SEAT-AccG4 data were derived from the NCBI Gene Expression Omnibus (GEO; https://www.ncbi.nlm.nih.gov/geo/) under the accession number GSE63874.

This file consists of 6 columns, each representing the chromosome number, start, end, strand, gene name and ID.

## Usage
To use the AccG4 coordinates in your research or analysis, you can download the `SEAT-AccG4.bed` file from this repository.
